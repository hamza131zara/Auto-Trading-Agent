## Integrity and maintenance rules

- The Git blob SHA values above are Git object hashes for the repository snapshot on `main`; they are not SHA-256 content digests.
- The DOCX/PDF SHA-256 values identify the uploaded source artifacts used in the comparison.
- Any later edit changes the corresponding Git blob SHA. Refresh this register when making a controlled documentation release; do not rewrite the canonical source hash.
- The register intentionally does not include its own hash. Its version and commit are available from Git history.
- Status is descriptive, not a substitute for explicit approval or a source-verification record.
- A document being present or owner-approved does not mean the corresponding implementation, test or legal assessment has been completed.
- Roadmap scope/phase order remains frozen unless the owner explicitly approves a dated change record.
