The first expanded live run checked 45 pool accounts and found 24 CPMM accounts, but only 20 received DEX Screener cross-checks; the report therefore remained incomplete. Independent reserve/price review remains outstanding. Remaining gates: only choose a higher-liquidity pool after the exact pair is cross-indexed and its on-chain owner/state layout is confirmed; run the full identity workflow for any selected candidate; verify the actual deployed program binary against a build from the pinned source (account executable/loader checks alone are insufficient); validate price, liquidity and volume against a truly independent source and on-chain reserves; select and approve production RPC/indexed providers and account plans; review current endpoint/schema/terms/quota/retention rules and approve a usage budget for the intended distribution model; and exercise the selected providers' live fallback/degraded behavior. A public rate limit, account-identity `MATCH`, or successful fixture test cannot satisfy these gates. Close Phase 6 only after all acceptance items are tested, critical identity and market data are independently validated, provider disagreement/fallback modes are proven safe, and replay is deterministic. Phase 7 token safety and all trade execution remain out of scope.
