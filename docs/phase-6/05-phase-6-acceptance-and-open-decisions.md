## Phase exit rule

**Phase 6 remains ACTIVE. Do not mark it complete yet.** The protocol-decoder implementation item is completed for the pinned Raydium CPMM candidate, but it has only synthetic/mock evidence. A guarded live-source validation runner is available in Phase 6.13, but no live-source run has yet been performed. Remaining gates: validate the integrated decoder against an independently sourced real pool using an owner-approved read-only RPC endpoint; verify current deployed program/source compatibility; select and approve the production RPC/indexed providers and account plans; confirm current endpoint/schema/terms/quota/retention rules and approve a usage budget; and test the chosen provider's fallback/degraded behavior. A public rate limit or successful fixture test cannot satisfy these gates. Close Phase 6 only after all acceptance items are tested, selected adapters and fallback behavior are documented, failure/degraded modes are proven safe, critical identity is independently validated, and replay is deterministic. Phase 7 token safety and all trade execution remain out of scope.
